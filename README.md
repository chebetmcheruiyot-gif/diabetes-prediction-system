Diabetes Prediction System
A machine learning-based web application that predicts the likelihood of diabetes in a patient based on key health parameters.

📌 About The Project
This system was developed to assist in early detection of diabetes by analyzing patient health data and providing a risk prediction. Early detection is critical in managing diabetes, especially in communities with limited access to specialist healthcare.

✨ Features

Input patient health parameters (glucose level, BMI, age, blood pressure, etc.)
Predicts whether a patient is at risk of diabetes
Displays prediction results in a simple, easy-to-understand interface
Built using a trained machine learning model


🛠️ Built With

Python — core programming language
Scikit-learn — machine learning model training and evaluation
Pandas & NumPy — data processing and analysis
Flask — web framework for the user interface
HTML/CSS — front-end interface


🚀 How To Run

Clone the repository:

bash   git clone https://github.com/chebetmcheruiyot-gif/diabetes-prediction-system.git
   cd diabetes-prediction-system

Install dependencies:

bash   pip install -r requirements.txt

Run the application:

bash   python app.py

Open your browser and go to:

   http://localhost:5000

📊 Model Details

Dataset: Based on standard diabetes health datasets
Algorithm: Classification model (e.g. Logistic Regression / Random Forest)
Evaluation: Trained and validated for accuracy and reliability
